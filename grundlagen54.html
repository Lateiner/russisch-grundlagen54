Russische Grammatik

Passives Partizip Präteritum

Das passive Partizip Präteritum beschreibt eine Handlung, die an einem Objekt bereits abgeschlossen wurde (z.B. „das gelesene Buch“). Es wird nur von vollendeten (СВ), transitiven Verben gebildet.

Wichtige Suffixe:

  • -нн- (bei Verben auf -ать / -ять) → прочитать → прочитанный
  • -енн- / -ённ- (bei Verben auf -ить / -еть / -ти) → построить → построенный
  • -т- (bei bestimmten kurzen Verben oder auf -ыть/-нуть) → открыть → открытый
